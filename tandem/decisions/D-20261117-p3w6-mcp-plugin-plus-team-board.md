## 原話

> 「其實我覺得 tandem這個桌面應用 我覺得需要它的多人看板 或許 房間功能 但不用在上面跟AI對話 而是用原本習慣的編譯器 IDE 然後用 MCP api 之類的連接 tandem 讓它做為一個工具 外掛的存在會比較好」 — @theroyatlas（chat）

> 「共用房間先延後」 — @theroyatlas（chat）

> 「我覺得先照中午的定位做 先在T3內建瀏覽器開 希望能高度還原」 — @theroyatlas（chat）

> 「所以tandem可以放在側邊攔 那我覺得這樣才是它正確用法欸 不要用桌面版 有辦法隨著該編譯器的深色 淺色模式去便吧」 — @theroyatlas（chat）

## 決定

Tandem 定位成「接各家編輯器的 MCP 外掛＋多人看板」。每個人在自己習慣的編輯器／T3 裡跟 AI 對話，Tandem 不做 AI 對話主介面；共用房間先延後。看板主要放在編輯器的側欄（例如 T3 內建瀏覽器）用，不以桌面版為主，深淺色跟著編輯器。不改用 T3 Code 延伸（不 fork），照這個定位繼續做 Tandem。

## 原因

不把人綁在某一個 AI 編輯器、也不要求換掉原本的對話習慣；Tandem 專心做多人共享的部分。放在側欄，邊寫程式邊看得到隊友和任務。

## 考慮過的其他做法

用 T3 Code（開源）延伸來做 Tandem；繼續在 Tandem 裡做 AI 對話；以桌面版為主
