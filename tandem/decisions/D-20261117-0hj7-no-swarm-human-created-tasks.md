## 原話

> 「Antigravity 的 Swarm 是一個人開很多 agent，算單人的，不進 Tandem。」 — @theroyatlas（chat）

> 「任務板要留一條「人自己建任務」的路，不要像 Cursor 只能由 agent 建。」 — @theroyatlas（chat）

## 決定

Antigravity 的 Swarm（一個人開很多 agent）算單人功能，不進 Tandem。照搬 Cursor 任務板時，要留一條人自己建任務的路，不像 Cursor 只能由 agent 建任務。

## 原因

Tandem 只放多人的功能；任務由人決定，符合「不讓 agent 自己決定要設計、開發什麼」。

## 適用範圍與什麼時候該重新檢視

照搬 Cursor／Antigravity 時要不要、要怎麼改
