## 決定

房間是一段團隊都能打字的對話，AI 跑在主持人的電腦、用主持人的帳號。背後是一個 GitHub Discussion：每個人說的話是一則留言（有帳號和網址，原話可以直接引用），AI 的回覆以 🤖 開頭貼回去，筆記放在討論的內文。大家打的話直接送進 AI，不用主持人先按。AI 什麼都能做，但改檔案、跑指令要主持人核准（因為是在主持人的電腦上）。主持人可以隨時請 AI 整理筆記（重點、決定、待辦、未解決問題），結束房間時也會整理並關閉討論。

## 原因

我們沒有自己的伺服器，別人連不到主持人的電腦；用 GitHub Discussion 不用設定網路，每句話都有作者和網址。動作要主持人核准，符合「在誰的電腦上跑，要那個人看過」。

## 考慮過的其他做法

主持人開對外分享連結（像 Omnigent）：即時，但要把電腦開給外面，設定和安全都麻煩。別人的訊息要主持人按一下才送出（像 T3 Code）：比較保守，但主持人要一直顧著。
