# 團隊協作功能

公開程式與團隊資料分開；以下訊息、分享與交接功能需要 `.tandem.json` 指定獨立的私人資料 repo。
開始新的回答、分享或交接前，程式會向 GitHub 確認資料 repo 仍是私人；無法確認時不開始新的內容傳送。

## 共享脈絡與任務

「更多動作 → 脈絡」可放背景、需求與圖。檔案使用版本檢查，衝突時必須重新載入，不會直接覆蓋。

任務可切換清單與看板，依成員篩選。PR 說明中的關閉關鍵字（例如 `Closes #8`）可將本 repo 的任務與 PR 連起來；關聯顯示不會代替 GitHub 關閉任務，也不代表已通過審查。

## Agent 問答

每個人自己啟用，預設關閉。開放狀態會公布給隊友，但遠端紀錄不能替這台電腦授權。只有本人選的本機工具與模型會用來回答。

一般 agent 用 `tandem_message_agent` 提問、`tandem_agent_replies` 收回答。問答在獨立的一次性程序中進行，只提供唯讀的共享脈絡、決定和任務工具；不能改檔、跑指令、改任務或要求人類授權。工具隔離不能確認時停止，不改用一般對話模式。對方電腦離線時問題保留；停止要求在對方下次同步時生效，不能撤回已消耗的額度。程序中斷後不自動重複呼叫模型。

「更多動作 → Agent 問答」只能閱讀、要求停止及封存；它不提供輸入對話的入口。主對話的下一輪會由 hook 收到備註。

## 對話分享與接續

1. 在「更多動作 → 對話與交接」挑選本機的專案對話。
2. 查看分享預覽，確認後才開始分享與同步這幾段的新內容。預覽後內容若已改變，要重新預覽。
3. 成員可以唯讀查看、用 `tandem_chat_read` 提供給自己的 agent，或建立自己的本機接續對話。

只讀取有相符專案路徑的 Claude Code、Codex 本機紀錄，以及帶有相符專案 ID 的 Tandem 對話。未提供相符路徑的來源不會猜測歸屬；找不到的紀錄不會分享。只選使用者與 AI 的文字，最多最近 100 則、單則 24000 字、單段 512 KB；附件、工具結果、權限卡和更早的內容不分享。疑似憑證會被拒絕。
超過 8 MB、跨過其他專案的紀錄不列入候選；多人房間與接續副本也不列入自己的分享，避免把別人的原話重新記成自己的。

接續會複製文字與來源，不複製憑證、原廠 session id 或原對話的動作權限。建立副本不呼叫模型；送出新訊息時才會開始自己的對話。分享開關不會因隊友的設定而開啟。關閉會停止同步並撤回目前版本，私人資料 repo 的 Git 歷史仍保留；離線時撤回要等待同步。

## 交接

選任務、接手人，填寫已完成、待辦與限制，確認後送出。筆記先存進私人資料 repo，再更改 GitHub 指派，成功後才會進接手人的開工報告。若指派或確認同步失敗，畫面會說明結果，不宣稱交接完成。

## 邀請與成員

邀請涵蓋程式與獨立資料 repo；其中一半失敗會單獨顯示。管理者可以移除成員，成員可自行離開。組織、團隊或其他來源的授權可能仍然存在，不能由移除直接存取權代替；未完整移除時顯示部分完成。

加入連結的秘密放在 URL fragment，只在產生者的本機保存；團隊資料 repo 只存雜湊。管理者可產生新連結，使舊連結失效。連結不授予 GitHub 權限，也不撤銷 GitHub 本身的邀請。接受 GitHub 邀請與驗證 Tandem 連結分開：若連結已過期，不會完成 Tandem 設定，但 GitHub 邀請可能已接受。其他裝置沒有明文連結時，由管理者重新產生。

## 驗證界線

單元、模擬協定、本機 git 雙端與 MOCK 畫面驗證各自記錄。真人雙機互問、真實模型的工具限制、不同來源對話與組織權限、安裝版更新，仍需要各人的實際環境驗收。`test:agents` 的新增情境會使用真實模型額度，本次只加入，不執行。
