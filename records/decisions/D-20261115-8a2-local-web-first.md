## 決定

學 T3 Code：一個本機核心加一套網頁介面。先做 `npx tandem` 在瀏覽器打開本機看板；之後把同一套介面包成桌面 app；要公開時再決定要不要架雲端網頁版。

## 原因

本機版不用架站、不用保管使用者的 GitHub 權杖、不用 Windows 簽章，你們馬上能用。介面只寫一次，之後放到桌面或雲端都不用重寫。

## 適用範圍與什麼時候該重新檢視

如果測試時發現「隊友要先裝東西」是最大的阻力，就提早做雲端網頁版。
