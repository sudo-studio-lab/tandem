## 原話

> 「我可以請你的 agent 做事，但要你看過、按下去，才會在你的電腦上執行；不做無人值守的自動執行」 — @theroyatlas（PARTNER-SCENARIOS.md，目標 G3）

## 問題

派工（請別人的 agent 做事）時，是不是一律要對方本人看過、按下去才執行？

## 卡住什麼

派工功能的設計。

要注意這和「可以反悔的決定先做、不用等對方同意」（D-20261115-c71）是兩件不同的事：那個是說**做決定**不用等人；這個是說**誰的電腦執行誰的指令**要經過本人。兩者可以同時成立。
